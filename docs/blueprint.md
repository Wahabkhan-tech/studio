# **App Name**: CapstoneFlow

## Core Features:

- Role-Based Access Control: Implement role-based access control to ensure that each user role (Admin, Teacher, Student) can only access the pages and components relevant to their responsibilities.
- Admin Module: Provide administrative functionalities including managing teachers, students, departments, and system settings.
- Teacher Module: Enable teachers to manage their groups, review proposals, manage attendance, review tasks, and evaluate student performance.
- Student Module: Allow students to complete their profiles, create or join groups, submit proposals, manage tasks, view attendance, and communicate within their groups.
- Attendance Management: Enable teachers to mark attendance, while students can view their attendance records. Prevent teachers from re-editing the attendance once submitted.
- Group Detail Page: Implement a role-aware Group Detail page with tabs for Overview, Members, Proposal, Tasks, Attendance, Chat, and Evaluation. The content and functionalities of each tab will vary based on the user's role.
- Intelligent Group Suggestions: Use a generative AI tool that suggests groups that a student might want to join, based on the student's profile, skills, and interests, to improve group forming and dynamics.

## Style Guidelines:

- Primary color: Deep violet (#673AB7) to reflect intellect and innovation.
- Background color: Light gray (#F5F5F5), nearly white, creating a clean and modern look.
- Accent color: Cyan (#00BCD4) to draw attention to interactive elements.
- Body and headline font: 'Inter' (sans-serif) for clear, modern text. 
- Use consistent and professional icons to represent different actions and sections, enhancing user experience.
- Employ a clean and structured layout, making use of cards, tables, and tabs to organize information efficiently.
- Subtle animations for transitions and feedback, providing a smooth user experience.
